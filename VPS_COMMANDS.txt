# TROUBLESHOOTING (If port 8000 is 'already in use'):
# Option A (Kill directly):
# sudo fuser -k 8000/tcp

# Option B (Find and kill manually):
# sudo netstat -tulpn | grep :8000
# (Look for the PID, then use: sudo kill -9 PID)

# 1. Allow Port 8000 (Very Important for API access):
# sudo ufw allow 8000/tcp

# 2. Enable/Disable Firewall:
# sudo ufw enable
# sudo ufw disable

# 3. Block a specific IP address:
# sudo ufw deny from 79.124.40.174

# 4. Check status and rules:
# sudo ufw status numbered

# 5. Unblock an IP (use the number from the list above):
# sudo ufw delete 5
